# Practicing Coding Interviews with Python

## Overview

This course is a focused prep tool for coding interviews, particularly for data science roles. It covers essential Python concepts and provides exercises that mimic real interview scenarios. The course is divided into four chapters, each with a corresponding Jupyter notebook.

## Directory Structure

- `Ch_1_Python_Data_Structures_and_String_Manipulation.ipynb`
- `Ch_2_Iterable_Objects_and_Representatives.ipynb`
- `Ch_3_Functions_and_Lambda_Expressions.ipynb`
- `Ch_4_Python_for_Scientific_Computing.ipynb`

Each notebook corresponds to a specific chapter and contains all the relevant lessons and exercises. Below is an outline of the topics covered in each chapter.

## Chapters Breakdown

### 1. Python Data Structures and String Manipulation
- **Key Concepts**: Lists, tuples, sets, dictionaries, and string manipulation.
- **Focus**: Use regular expressions to extract patterns from text. These basics are crucial for tackling more complex problems.

### 2. Iterable Objects and Representatives
- **Key Concepts**: Iterables, list comprehensions, combining iterables, generators.
- **Focus**: Understanding how to efficiently create and work with iterable objects.

### 3. Functions and Lambda Expressions
- **Key Concepts**: Functions with variable arguments, lambda functions, `map()`, `filter()`, `reduce()`, recursion.
- **Focus**: Functional programming techniques in Python, especially with anonymous functions.

### 4. Python for Scientific Computing
- **Key Concepts**: NumPy arrays vs. lists, pandas DataFrame manipulation, data visualization (scatterplots, histograms, boxplots).
- **Focus**: Tools and techniques for scientific computing, crucial for data analysis tasks.

## Usage Notes
- **Structure**: Work through each chapter’s notebook sequentially.
- **Practice**: Attempt exercises before reviewing solutions. Explore variations of problems for deeper understanding.
- **Goal**: Build confidence and fluency in solving Python coding problems, especially in the context of data science interviews.
